# 清爽知乎

加宽知乎正文，去掉侧栏和划线词，并补上几个常用功能。

## 安装

- [GitHub](https://github.com/huanfe1/zhihu-clean/releases/latest/download/zhihu-clean.user.js)
- [Greasy Fork](https://greasyfork.org/zh-CN/scripts/443919)

## 功能

- 加宽各页面的正文
- 切换深色和浅色
- 去掉文章里的高亮词
- 去掉段落划线
